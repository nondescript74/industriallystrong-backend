The Technical Build
PYTHON
MEETS
SWIFT
KanjiKanaTrainer is backed by a custom Python data pipeline that fetches, processes, and packages stroke data into Swift-compatible JSON — with a full offline mode so the app works without a network connection.
  • Python stroke fetcher — Custom tool fetching SVG stroke data for all 100 characters
  • Dual JSON output — Standard and Swift-compatible formats generated automatically
  • Built-in offline mode — All 100 characters embedded, no internet required
  • SwiftUI rendering — Stroke animation rendered natively on iOS
  • Accurate stroke counts — Verified stroke data for every character in the set
