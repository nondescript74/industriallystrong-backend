# industriallystrong-backend

Static pages for **z.industriallystrong.com**, published by GitHub Pages from the `main` branch.

There is no server in this repository. Every page is plain HTML, and anything merged to `main` goes live on z.industriallystrong.com within minutes, so changes go through a pull request.

## What publishes

- The `.html` pages at the repository root and under `public/`.
- `reczipes/support/` and `keeptrack/support/`, which forward to the support pages in `public/`.
- `.well-known/security.txt`.
- `CNAME` sets the custom domain.

`_config.yml` keeps the repository's own documents (this README, `SECURITY.md`, `LICENSE`) off the site.
