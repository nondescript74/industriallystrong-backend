AI
The AI Layer
CLAUDE
STRUCTURES
THE CHAOS
Raw OCR output is noisy — especially from old cards. Claude's role is to take that messy text and return structured JSON: title, servings, ingredients with quantities and units, numbered steps. The model handles abbreviations, inferred measurements, and even incomplete sentences.

User-Controlled API Key

Rather than embedding a shared key, Reczipes uses an onboarding flow where users enter their own Claude API key — full control, zero vendor dependency, no subscription tier required.
