# Security Policy

## Reporting a Vulnerability

If you discover a security issue related to IndustriallyStrong infrastructure,
please report it privately.

Contact:
build.zmarter@gmail.com

Please do not open public issues for security vulnerabilities.

## Scope

Security-sensitive areas include:

- API endpoints
- authentication or authorization logic
- infrastructure configuration
- exposed credentials or tokens
- CORS configuration
- build pipeline secrets

## Responsible Disclosure

Reports will be reviewed and addressed as quickly as possible.
